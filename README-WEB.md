# הדמיה למסכים — גרסת ווב (מחשב + אייפון + אנדרואיד)

## 1. במחשב: קובץ אחד, אופליין
הקובץ הוא **`Visualizer.html`** (בתיקייה הראשית).
- פותחים אותו בלחיצה כפולה, ב-Chrome או ב-Edge.
- לא צריך אינטרנט, שרת או התקנה.
- הוא כולל את כל היכולות: סרטונים, ייצוא MP4 ופתיחה מהצעת מחיר.
- אפשר להעתיק אותו לכל מחשב, לבד, בלי קבצים נוספים.
- כדי לשמור ב-OneDrive, שומרים לתיקיית OneDrive שבמחשב והסנכרון מעלה אותה.

**בנייה מחדש אחרי שינוי בקוד:** מריצים את הפקודה הבאה בתיקייה `web`. היא יוצרת מחדש את `Visualizer.html`.
```
python build_local.py
```

**חיבור מ-LED Quote:** פותחים את הקובץ עם בקשה בכתובת:
```
file:///C:/.../Visualizer.html#quote=<base64url של ה-JSON>
```
המבנה זהה לגרסת המחשב (`examples/viz_request_example.json`). base64url פירושו base64 עם `-` ו-`_` במקום `+` ו-`/`, בלי `=` בסוף.

## 2. בטלפון: GitHub Pages (חינם), ואחרי הפתיחה הראשונה אופליין
GitHub Pages רק מחזיק את הקבצים, ואין שרת שצריך להפעיל או לתחזק. בפתיחה הראשונה הטלפון שומר עותק של כל האפליקציה, ומאז היא עובדת גם במצב טיסה.

### העלאה (פעם אחת)
1. נכנסים ל-https://github.com, יוצרים חשבון חינמי, ולוחצים **New repository**.
   - **שם:** למשל `visualizer`
   - **סוג:** **Public**. ב-GitHub Pages בחינם המאגר חייב להיות ציבורי.
   - יוצרים את המאגר.
2. במאגר לוחצים **Add file → Upload files**.
3. גוררים לשם את **כל מה שבתוך התיקייה `web`**, את התוכן ולא את התיקייה עצמה, כולל התיקיות `js`, `css` ו-`vendor`. אחר כך לוחצים **Commit changes**.
4. נכנסים ל-**Settings → Pages**:
   - **Source:** בוחרים *Deploy from a branch*.
   - **Branch:** בוחרים `main` ו-`/ (root)`.
   - לוחצים **Save**.
5. אחרי כדקה מופיעה הכתובת:
   ```
   https://<שם-המשתמש>.github.io/visualizer/
   ```

### התקנה בטלפון
- **אייפון:** פותחים את הכתובת ב-**Safari**, לוחצים על כפתור השיתוף ⬆️ ובוחרים **"הוסף למסך הבית"**.
- **אנדרואיד:** פותחים את הכתובת ב-**Chrome**, נכנסים לתפריט ⋮ ובוחרים **"התקן אפליקציה"** או **"הוסף למסך הבית"**.

מעכשיו יש אייקון על המסך, והאפליקציה נפתחת במסך מלא, גם בלי אינטרנט.

### עדכון גרסה
מעלים שוב את הקבצים ששונו למאגר. הטלפון מוריד את העדכון ברקע, והוא מופיע בפתיחה שאחריה.

## 3. שמירה ב-OneDrive (בלי רישום ובלי הגדרות)
**בטלפון:**
- **שמירה:** בוחרים "שמירה" או "ייצוא", ואז **"שתף / שמור ב-OneDrive או בקבצים"**.
  - בתפריט השיתוף בוחרים **OneDrive**, ושם בוחרים תיקייה.
  - באייפון אפשר גם **"שמור בקבצים"**, ואז תיקייה ב-OneDrive.
- **פתיחה:** בוחרים "פתח פרויקט" ובבורר הקבצים בוחרים את OneDrive.

צריך שאפליקציית OneDrive תהיה מותקנת בטלפון.

**במחשב:** שומרים ופותחים מתיקיית OneDrive שבמחשב.

**קובץ הפרויקט `.vizproj`:** אותו קובץ נפתח בטלפון, ב-`Visualizer.html` במחשב, ובאתר.

## מה כל מכשיר מציג
| | מחשב | טלפון / טאבלט |
|---|---|---|
| תמונה מהשטח, קנה מידה, מסכים, פרספקטיבה, כרטיס פרטים | ✓ | ✓ (מותאם למגע) |
| תוכן תמונה על מסך | ✓ | ✓ |
| סרטונים, ניגון בתצוגה, ייצוא MP4 | ✓ | — (סרטונים נשמרים בפרויקט ומוצגים ככרטיס פרטים) |
| פתיחה מהצעת מחיר | ✓ | — |
| שמירה אוטומטית ושחזור | ✓ | ✓ |

- **שינוי ידני של התצוגה:** ⚙ הגדרות → תצוגה.
- **שפה:** ⚙ הגדרות → שפה.

## אופציונלי: התחברות מובנית ל-OneDrive
באתר אפשר גם להתחבר ל-OneDrive מתוך האפליקציה ולדפדף בתיקיות. זה לא נדרש, כי השמירה דרך תפריט השיתוף מספיקה.

1. ב-https://entra.microsoft.com נכנסים ל-**App registrations** ← **New registration**.
2. **Supported account types:** *Accounts in any organizational directory and personal Microsoft accounts*.
3. **Redirect URI:** פלטפורמה **Single-page application**, עם הכתובת `https://<שם-המשתמש>.github.io/visualizer/auth.html`.
4. מעתיקים את ה-**Application (client) ID** לקובץ `config.js` ומעלים אותו שוב.

בקובץ המקומי `Visualizer.html` ההתחברות המובנית לא זמינה, כי היא דורשת אתר עם https.

## בדיקה מקומית (למפתח)
`run_web.bat` מריץ שרת בדיקה בכתובת http://localhost:8080. אין צורך בו לשימוש רגיל.
